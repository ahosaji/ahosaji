# Support

- Use [Discussions](https://github.com/ahosaji/ahosaji/discussions) for questions, usage help, and ideas.
- Use [Issues](https://github.com/ahosaji/ahosaji/issues/new/choose) for reproducible bugs and feature requests.
- Report vulnerabilities privately using [SECURITY.md](./SECURITY.md).

Before opening an issue, check existing issues and include enough detail to reproduce the problem. Remove API keys, tokens, passwords, and personal information from anything you share.
