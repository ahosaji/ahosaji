# Security Policy

## Reporting a vulnerability

Found a security issue in the Ahosaji API? Please report it **privately** — do
**not** open a public issue.

- Email **hello@ahosaji.com**, or
- Open a private advisory: **Security → Advisories → Report a vulnerability**.

We'll acknowledge your report as soon as we can and keep you posted on the fix.
Thanks for helping keep Ahosaji and its users safe.
