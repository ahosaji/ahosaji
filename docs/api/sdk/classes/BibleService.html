    getV1Parallel

    • getV1Parallel(
          __namedParameters: {
              end?: string;
              preferAligned?: string;
              ref?: string;
              start?: string;
              translations: string;
          },
      ): CancelablePromise<ParallelResult>

      Cross-translation parallel query (signature feature) Returns the same verse(s) across multiple translations side-by-side. Each per-translation entry has present: bool so missing-in-one-tradition verses (Tobit Vulgate vs Rahlfs LXX divergence) are explicit, not 404s.

      Versification-aware mode (prefer_aligned=1): the FIRST translation in translations becomes the anchor, and other translations show their semantic equivalent of the anchor's verse per the versification mapping tables — even when both translations have the queried ref directly. This surfaces renumbering shifts (e.g. ar:SIR.1.20 = en:SIR.1.16) and Vulgate-only verses (no Greek-LXX equivalent → present:false + mapping_note). When the table has no entry for the queried ref, falls back to identity matching transparently.
