# Contributing

Thanks for your interest in Ahosaji.

- **Issues** — use GitHub Issues for bugs and feature requests. Include steps to reproduce and expected vs. actual behavior.
- **Discussions** — use GitHub Discussions for questions, ideas, and general chat.
- **Pull requests** — keep them focused and small. Run `pnpm -r typecheck`, `pnpm test`, `pnpm test:python`, `pnpm validate` and the production dependency audit before opening. PostgreSQL integration tests require a disposable `TEST_DATABASE_URL`; CI supplies one.
- **Security** — do **not** open a public issue for vulnerabilities; see [SECURITY.md](./SECURITY.md).

By contributing you agree your contributions are licensed under the same terms as this repository.
